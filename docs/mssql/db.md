keys below are what actually exists — not a transcription.

## Legend

| Mark | Meaning |
|---|---|
| **PK** | Part of the primary key |
| → `table.column` | Foreign key target |
| 🆕 | Column added for process mining — did not exist in the original PostgreSQL design |
| *(whole table new)* | Table has no PostgreSQL counterpart |
| *(replaces the … ENUM)* | Reference table standing in for a PostgreSQL `ENUM` type |

Every `datetime2(3)` column stores **UTC**. Every `nvarchar(max)` holding JSON has an
`ISJSON` check constraint.
